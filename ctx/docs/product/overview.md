# Product Overview

- Path: `ctx/docs/product/overview.md`
- Changed: `20260715`

## Product Identity

`@flancer32/alarisa-desk` is the desktop browser/PWA composition package through which the Principal will use desktop-oriented Alarisa interaction.

## Product Scope

The package owns desktop presentation, navigation, workspace composition, and desktop representations of Signals, Discussions, and other Principal–Double interaction.

## Product Boundaries

In scope: large-screen and keyboard-oriented client interaction.

Out of scope: server authority, durable Alarisa state, shared communication contracts, mobile-specific interaction, and platform-native adapters.

## Current Boundary

Only the package identity and responsibility boundary are accepted. Concrete pages, flows, layouts, widgets, and UI states are not yet defined.
