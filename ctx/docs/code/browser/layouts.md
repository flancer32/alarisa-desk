## Purpose

Record accepted structural layouts for the desktop browser application.

## Layout Catalogue

The connected-channel shell contains a channel label, title, bounded availability explanation, and a link back to the host channel choice.

## Region Rules

The shell remains keyboard accessible and readable on a large screen without introducing workspace regions.

## Layout Usage

The shell layout is used only by the desktop channel entry page.
