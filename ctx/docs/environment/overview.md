## Runtime Model

The accepted baseline is an installable browser/PWA application assembled from ESM npm packages. Node.js 20 or newer supports package development and verification; the concrete browser framework and delivery environment are not selected.

## Environment Constraints

Do not infer deployment topology, offline guarantees, push delivery, or browser storage before those choices are documented upstream.
